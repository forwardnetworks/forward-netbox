# Consolidated dependency bumps for 2.9.2

## Goal

Close every open Dependabot pull request and every open Dependabot alert that
has a fixed version, in one reviewed change.

## Constraints

- `constraints.txt` stays the authority on what ships and is untouched: none of
  these packages is a runtime dependency of the plugin.
- Every action in `release.yml` stays SHA-pinned. The SHAs are the ones
  Dependabot proposed; nothing here was resolved by hand.
- `requirements-release.txt` is regenerated by the exact `pip-compile` command
  recorded in its header, with hashes, on Python 3.14.

## Touched Surfaces

- `poetry.lock` - `python-dotenv` 1.2.2 -> 1.2.3, `pre-commit` 4.6.0 -> 4.6.2
  (#283, #211).
- `requirements-release.txt` - `pip` 26.1.2 -> 26.2.1 (GHSA-qwm4-qh6w-59xr),
  `python-dotenv` 1.2.3, `pre-commit` 4.6.2, `twine` 6.2.0 -> 7.0.0 (#117).
- `.github/workflows/release.yml` - `actions/checkout` 7.0.1 (#88),
  `actions/setup-python` 7.0.0 (#165), `actions/upload-artifact` 7.0.1 (#89),
  `actions/download-artifact` 8.0.1 (#87), `pypa/gh-action-pypi-publish` 1.14.2
  (#166).

## Approach

Nine Dependabot pull requests collided pairwise on two files, so merging them
in sequence meant a rebase-and-wait cycle per pull request. They are applied
here as one change instead, and closed as superseded once this merges.

`sqlparse` 0.6.0 (#219, three high alerts) merged on its own first, because it
was the one that gated #288.

Two of the nine were obsolete: #310 (`pip`) and #117's `poetry.lock` half
(`twine`) targeted entries that the 2.9.1 lockfile correction had already
removed - neither package is in `poetry.lock` on `main`. The `pip` alert is
real only against `requirements-release.txt`, and that is where it is fixed.

`paramiko` GHSA-r374-rxx8-8654 is `low` with no fixed version and stays under
the existing `PYSEC-2026-2858` waiver in `check_release_preflight.py`.

## Validation

- `invoke harness-check`, `invoke harness-test` (334), `pre-commit` on the
  three files.
- `poetry check --lock` passes.
- After merge: the open Dependabot alert list shows only `paramiko`.

## Rollback

Revert. The previous SHAs and pins are in the diff.

## Decision Log

- **One pull request rather than nine.** The nine were already conflicting with
  each other after the first merge. Applying them together costs one review
  and produces the same tree.
- **Version comments trimmed to fit yamllint's 80 columns**, matching the
  existing `# v7` style rather than the full `# v7.0.1` Dependabot writes.
