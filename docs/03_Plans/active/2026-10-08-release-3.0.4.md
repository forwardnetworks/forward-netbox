# Release 3.0.4

## Goal

Cut `3.0.4` on `main` (the NetBox 4.7 lane). It carries what landed after `3.0.3`:
OSPF instances whose desired name another instance on the device already holds are
kept under a stable `<name> #<process_id>` variant instead of being skipped;
endpoints from Infoblox and Palo Alto appliances are named by vendor rather than the
first `sysDescr` word; `netbox-dlm` 0.10.1 and 0.10.2 are accepted alongside 0.10.0;
the support bundle's primary-IP section gains endpoint prefix-length, site placement
and fallback-reason figures; and the UI gate runs on `agent-browser` instead of
Playwright.

## Constraints

- Version surfaces (`pyproject.toml`, `forward_netbox/__init__.py`,
  `forward_netbox/utilities/fast_baseline.py`,
  `forward_netbox/tests/test_runtime_dependency_check.py`, the README
  compatibility tables) must all read `3.0.4` together.
- The tested runtime stays NetBox `4.7.2` and `netbox-branching` `1.2.1`.
- No code change in this commit: every functional change already landed as `#538`,
  `#539` and `#540`, each gated on its own branch.

## Touched Surfaces

- `pyproject.toml`, `forward_netbox/__init__.py`,
  `forward_netbox/utilities/fast_baseline.py`,
  `forward_netbox/tests/test_runtime_dependency_check.py`.
- `README.md`, `docs/README.md`, `docs/01_User_Guide/README.md`, `CHANGELOG.md`.
- This plan.

## Approach

`scripts/release.py 3.0.4 --write` bumps every version surface and the
fast-baseline pin and regenerates `CHANGELOG.md` from the README compatibility
table.

- **`#538`.** OSPF name clashes resolve to `<name> #<process_id>`; the bundle gains
  `interface_ip4_prefix_lengths`, `site_placement` and `fallback_reasons`.
- **`#539`.** Infoblox and Palo Alto endpoints are named by vendor OID and profile;
  `netbox-dlm` 0.10.1 and 0.10.2 are accepted (tested pin 0.10.1); the OSPF clash
  lookup runs only after a clash so repeated rows keep the zero-query cache path.
- **`#540`.** `agent-browser` replaces Playwright as the UI-gate driver; a cold
  NetBox boot may take 30 minutes before it is called unhealthy; a rescued bulk shard
  is indexed with one search-cache job and a job timeout escapes that indexing.

## Validation

- `#538`, `#539` and `#540` each passed their own pre-push gate before merge.
- `scripts/release.py 3.0.4 --write` verify step, then full `invoke ci` and
  `invoke artifact-test` on the release tree.

## Rollback

This commit is a version bump and changelog entry only. Reverting it restores the
previous version surfaces; none of the merged changes carries a migration.

## Decision Log

- **Tested pin stays at netbox-dlm 0.10.1.** 0.10.2 is accepted but not yet on PyPI,
  so the gate cannot install it; move the pin after it publishes.
- **The UI harness change ships in the same release as its first full use.** The
  release gate is the first place `agent-browser` runs against the exact release tree.
