# Advance the release provenance anchor to 2.7.12

## Goal

Complete the post-release bookkeeping for 2.7.12: pin the anchor to the tag and
its documentation bridge, and tell operators that 2.7.12 is what they should be
running.

## Constraints

- The bridge is fixed at the first commit after the tag and cannot be
  reclaimed, so the anchor can only pin `b9f5b76`.
- Exactly one row in each of the three tables may say "Current release".
- `v2.7.10` stays in `UNPUBLISHED_RELEASE_TAGS`; it published nothing and must
  never be promoted.
- Local `verify_release_provenance.py` cannot run to completion on this host;
  the publish workflow runs the identical verifier and is fail-closed.

## Touched Surfaces

- `scripts/verify_release_provenance.py` (anchor pair)
- `scripts/check_harness.py`, `scripts/tests/test_tasks.py` (prior-tag literals)
- `.github/workflows/release.yml` (tag fetch)
- `README.md`, `docs/README.md`, `docs/01_User_Guide/README.md`, `CHANGELOG.md`

## Approach

Mechanical, and the same shape as every prior anchor advance: the five
hand-maintained copies of the prior tag move together, and the compatibility
tables promote 2.7.12 and demote the outgoing release in the same change so the
anchor and the tables agree again.

The lineage for the next release will walk from `b9f5b76`. That walk needs at
least four commits, which means the next release again requires its production
content to land as its own reviewed pull request ahead of the release commit.
`scripts/check_release_lineage.py` will confirm it before anything is tagged;
this cycle it reported four, correctly, while the tag could still be changed.

## Validation

`invoke ci` locally, which runs the harness - including the check that the
anchor is not behind the table - and the full `scripts/tests` suite.

## Rollback

Revert. The anchor returns to `v2.7.11` and the tables call the outgoing release
current, which would then be wrong on both counts.

## Decision Log

- **Promote and re-anchor in one change.** Splitting them is how the anchor went
  stale before: each half is silent on its own, and the harness ties them
  together so neither can be skipped quietly.

## Open

- Nothing for 2.7.12.
