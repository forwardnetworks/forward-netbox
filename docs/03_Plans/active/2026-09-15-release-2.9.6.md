# Release 2.9.6

## Goal

Cut `2.9.6` on the `maint/2.9.x` lane: bump every version surface and the
fast-baseline runtime pin together, and record the release note for the
nine items already merged to `maint/2.9.x`.

## Constraints

- Version surfaces (`pyproject.toml`, `forward_netbox/__init__.py`,
  `forward_netbox/utilities/fast_baseline.py`,
  `forward_netbox/tests/test_runtime_dependency_check.py`, the README
  compatibility tables) must all read `2.9.6` together, or
  `check_harness.py` refuses the release - see
  [[fast-baseline-version-pin-trap]].
- No code change in this commit: every functional change already landed as
  its own reviewed PR (#397-#400, #402, #403).
- No customer names, identifiers or scan-matching hostnames in this plan,
  the changelog entry, or the release commit message.

## Touched Surfaces

- `pyproject.toml`, `forward_netbox/__init__.py`,
  `forward_netbox/utilities/fast_baseline.py`,
  `forward_netbox/tests/test_runtime_dependency_check.py`
- `README.md`, `docs/README.md`, `docs/01_User_Guide/README.md`,
  `CHANGELOG.md`
- this plan

## Approach

`scripts/release.py 2.9.6 --write` bumps every version surface and the
fast-baseline pin in the same commit, and regenerates `CHANGELOG.md` from
the README compatibility table. The nine items it covers:

1. The fast baseline stays on when Cisco ACI maps are enabled.
2. ACI static port bindings, subject filters, and APIC-derived fabrics.
3. Route-map entries link to the prefix lists and community lists they
   match.
4. Nine operator audits become pages on the sync.
5. An ingestion issue keeps its own message instead of a generic one.
6. A manual device delete releases the plugin's own ownership records
   instead of being refused by them.
7. The orphan quarantine badge counts only the devices the prune button
   actually deletes.
8. The uncovered card explains that its tag-filtered device list is shared
   across every sync, not this sync's current count.
9. `dcim.inventoryitem`'s drift comparison counts a module-native row as a
   delete instead of declining the whole model's measurement.

Full design detail for each item lives in
`docs/03_Plans/completed/2026-09-12-fast-baseline-aci-routing-audits-tranche.md` (items 1-4) and
`docs/03_Plans/active/2026-09-14-device-cleanup-honesty.md` (items 6-9);
item 5 shipped as its own PR (#398) without a repo-copy plan file.

  and abandoned after finding it was reprocessing an unrelated ~1M-row

  [[acceptance-org-shared-with-other-projects]]); the nine merged,
  CI-green PRs are the validation record for this release.

## Rollback

This commit is a version bump and changelog entry only - no functional
code changes ship in it (those already merged as separate PRs). Reverting
it restores the previous version surfaces; the functional PRs would need
their own separate reverts if any of them needed to be undone.

## Decision Log

- **Ship on `invoke ci` alone, without a fresh full acceptance proof.**
  The acceptance re-run's outsized diff was verified to be concentrated in
  models none of the six PRs touch, so it carries no signal about this
  release's correctness; chasing it further would have cost hours against
  a live environment that turned out not to be a clean comparison point.
- **One release-cut plan file for the version bump, not a rewrite of the
  item-level plans.** Those already carry full design and decision-log
  detail; duplicating them here would drift out of sync with the merged
  code.
