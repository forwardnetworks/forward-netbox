# Advance the release provenance anchor to 2.7.11

## Goal

Complete the post-release bookkeeping for 2.7.11: pin the anchor to the tag and
its documentation bridge, and tell operators that 2.7.11 is what they should be
running.

## Constraints

- The bridge is fixed at the first commit after the tag and cannot be
  reclaimed, so the anchor can only pin `087a15c`.
- Exactly one row in each of the three tables may say "Current release".
- `v2.7.10` stays in `UNPUBLISHED_RELEASE_TAGS`. It published nothing and must
  never be promoted.
- Local `verify_release_provenance.py` cannot run to completion on this host;
  the publish workflow runs the identical verifier and is fail-closed.

## Touched Surfaces

- `scripts/verify_release_provenance.py` (anchor pair)
- `scripts/check_harness.py`, `scripts/tests/test_tasks.py` (prior-tag literals)
- `.github/workflows/release.yml` (tag fetch)
- `README.md`, `docs/README.md`, `docs/01_User_Guide/README.md`, `CHANGELOG.md`

## Approach

Mechanical, and the same shape as every prior anchor advance: the five
hand-maintained copies of the prior tag move together, and the compatibility
tables promote 2.7.11 and demote the outgoing release in the same change so the
anchor and the tables agree again.

The one thing worth noting is what the anchor now skips. `v2.7.10` sits between
`v2.7.9` and `v2.7.11` in the tag list but published nothing, so it is recorded
as unpublished rather than anchored. The next release's lineage therefore walks
from `087a15c`, and `scripts/check_release_lineage.py` will confirm it holds at
least four commits before anything is tagged - which is the check `v2.7.10` did
not have.

## Validation

`invoke ci` locally, which runs the harness - including the check that the
anchor is not behind the table - and the full `scripts/tests` suite.

## Rollback

Revert. The anchor returns to `v2.7.9` and the tables call the outgoing release
current, which would then be wrong on both counts.

## Decision Log

- **Promote and re-anchor in one change.** Splitting them is how the anchor went
  stale before: each half is silent on its own, and the harness ties them
  together precisely so that neither can be skipped quietly.
- **Keep `v2.7.10` in the unpublished list permanently.** It is a record of
  which tags never published, not a list of active exemptions.

## Open

- Nothing for 2.7.11.
