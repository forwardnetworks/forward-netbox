# Advance the release provenance anchor to 2.8.6

## Goal

Point the anchor at `v2.8.6` and its bridge, and promote the release in the
compatibility tables.

## Why

A stale anchor grows the reviewed commit range on every release until GitHub
expires the oldest checks inside it, and the harness fails while the anchor
disagrees with the release the table calls current.

## Constraints

- The anchor tag and the README "Current release" row must name the same
  version.
- The bridge must be the first first-parent commit after the tag,
  documentation-only.

## Touched Surfaces

- `scripts/verify_release_provenance.py` - the anchor pair
- `.github/workflows/release.yml`, `scripts/check_harness.py`,
  `scripts/tests/test_tasks.py` - the tag each pins
- `README.md`, `docs/README.md`, `docs/01_User_Guide/README.md`, `CHANGELOG.md`

## Approach

The bridge for `v2.8.6` is `1553139`, generated by `scripts/release.py`,
exactly one documentation file, verified with the release verifier's own
predicate. Third consecutive release with a clean generated bridge;
`BRIDGE_CONTENT_EXCEPTIONS` stays empty.

## Validation

`check_harness.py`, which runs the verifier's bridge rule against the pinned
pairing, plus the harness suite.

## Rollback

Revert. The anchor returns to `v2.8.5` and the harness fails on the promoted
table.

## Decision Log

- **Advance in the same session as the release**, as with every release since
  the anchor-staleness incident.

## Open

- `_github_json` in the release verifier needs a bounded retry, or keep-alive.
  This release's tag step failed twice on a HOST fault - this machine stalls
  HTTP responses on `Connection: close`, which urllib always sends (measured:
  close 1/6, keep-alive 6/6, gh and curl unaffected). It shipped via an
  environment-only sitecustomize shim that drops that header for the local
  pre-tag verification; the tagged tree is untouched and CI re-verifies from
  the tag on GitHub runners. The durable fix belongs in 2.8.7, and the host
  fault - worsening since 2026-08-06 - needs surgery outside a release window.
