# Release 3.0.19

## Goal

Ship the corrected release that replaces the withdrawn 3.0.18: the site rules table's tag
dropdown works inside NetBox's page (the plugin selects opt out of NetBox's dropdown
enhancer), the Predict status check works on Forward 26.11 and later (forward-sdk 0.1.40,
predicted snapshots requested only by the status check), and every UI check is an
agent-browser journey that the release gate requires.

## Constraints

- No customer names, network ids, snapshot ids or hostnames in the repo.
- Plugin only: no migration, and the bundled queries do not change, so no republish.
- 3.0.18 was published, found broken, and withdrawn (PyPI release deleted, GitHub release
  deleted; the git tag cannot be removed because of a repository rule). The PyPI filenames
  for 3.0.18 cannot be reused, so this is 3.0.19 and 3.0.18 is marked withdrawn.
- `development/constraints-upgrade-from.txt` keeps `forward-sdk==0.1.36`, the pin of the
  previous published release (3.0.17).
- The release-time sensitive-pattern feed is a CI secret and cannot be read locally, so
  the cut runs with the unverified-parity flag; the publish workflow can still refuse.

## Touched Surfaces

- `forward_netbox/widgets.py`, `change_control/predict.py`, `change_control/workspace.py`,
  `pyproject.toml`, `poetry.lock`, `constraints.txt`, `scripts/validate_sbom.py`.
- UI gate: `scripts/forward_ui_harness.mjs`, `scripts/ui/`, the seed command.
  Plan: `2026-11-20-browser-uat-gate.md`.

## Approach

The tranche (PR #651) went through two code-reviewer audits and the fixes are in its
commits. Then `scripts/release.py 3.0.19` through the usual lineage.

## Validation

- Tranche: `invoke ui-test` 13 journeys pass, broken-on-purpose checks fail as intended;
  85 change-control tests; 468 scripts tests. The full gate runs inside `--write`.
- Not verified: against a live Forward 26.11; the Predict fix is unit-tested against the
  SDK signature only.

## Rollback

Revert the release. The dropdown and Predict changes are small and independent.

## Decision Log

- Version 3.0.19, not a re-release of 3.0.18: PyPI never accepts the same filenames again.
